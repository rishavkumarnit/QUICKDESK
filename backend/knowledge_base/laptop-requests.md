# Laptop replacement and hardware issues

This is a fictional QuickDesk demonstration policy. Employees needing a replacement laptop should raise an IT ticket with the current asset identifier, a description of the problem, and how it affects their work. Include the operating system and any visible error messages. A support agent will review troubleshooting options and determine whether hardware assessment is needed. Replacement requests require the appropriate manager and IT approvals.

For poor battery life, describe how long the battery lasts and whether the device works normally on its approved charger. Do not open the laptop or attempt to replace internal components yourself. If the battery appears swollen, the laptop emits smoke, or it becomes unusually hot, stop using the device and contact IT immediately. Disconnect power only if it is safe to do so.

Do not discard company equipment or purchase replacement hardware expecting automatic reimbursement. IT will provide handling and return instructions after reviewing the request. Agents must not promise a specific replacement model or delivery date before approval.
