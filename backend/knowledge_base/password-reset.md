# Password reset and account recovery

This is a fictional QuickDesk demonstration policy. Employees should reset a forgotten company password through the password reset option on the company sign-in screen. Use only the company sign-in page you normally access; do not follow unsolicited password reset links in email. Complete the registered multifactor authentication challenge and choose a unique password that is not used for personal accounts.

If you cannot access your registered authentication method, open an IT ticket describing the access problem. Support must verify your identity using the established internal process before restoring access. An agent must not promise that verification can be bypassed or that an account has already been unlocked.

After resetting the password, sign out and back in to applications that continue requesting the old credentials, including the VPN. Never place passwords, recovery codes, security answers, or one-time authentication codes in a ticket. Report an unexpected password change or unfamiliar authentication prompt as a potential security incident.
