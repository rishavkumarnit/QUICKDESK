# Access to shared drives

This is a fictional QuickDesk demonstration policy. Employees requesting shared-drive access should submit an IT ticket stating the drive or folder name, the business reason, and the level of access needed. Include the name of the data owner or team responsible for the folder if known. Request only the minimum permissions necessary to do your work.

Access requires approval from the data owner. Finance folders may contain restricted information, so an employee's department membership does not automatically grant permission. Support should obtain the required approval before making any changes and should not promise that access has already been granted.

If access previously worked, provide the exact error message and indicate whether you are connected to the company network or VPN. Do not share another employee's login or ask them to copy restricted files into a public folder. The agent can use the ticket to track the approval and troubleshooting process while maintaining the original access restrictions.
